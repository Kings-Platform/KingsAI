# People (people-ksa.com) job board

`people-ksa.com`, a Saudi job board.

## Steps

Quick Apply with the email → details → Application Questions → Review (a required T&C
checkbox) → Submit.

## Fields

- The phone's dial-code combobox defaults to +966: set the profile's country code.
- Salary fields are in SAR, digits only — a currency decision from the answer bank, not a guess.
- JS reads of the whole `innerText` are blocked: read label/value pairs instead.
