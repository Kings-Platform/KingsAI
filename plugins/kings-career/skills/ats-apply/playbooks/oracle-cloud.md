# Oracle Cloud (Candidate Experience)

`<company>.fa.<region>.oraclecloud.com/hcmUI/CandidateExperience/…`. Account required (user).

- **Profile:** `my-profile/info` → "Edit Personal Information" opens a modal with personal
  data, Education, **Experience**, documents and links. **Nothing saves until "UPDATE"** at the
  bottom of the modal ("Your profile was updated").
- **Experience:** each item has Edit / Delete (Delete asks no confirmation). Ids
  `employerName-N`, `jobTitle-N`, `employerCity-N`, `achievements-N` (native setter +
  `input`/`change` persists) and comboboxes for month, year and country: click, type
  ("February", "2023", "<Country>"), Enter. "Current Job" disables the end date. The block's
  button is "Save" (edit) or "Add Experience" (new).
- A LinkedIn import brings duplicates and any agency the facts page says to drop: delete and
  leave one entry per real role.
- The session expires ("End Session / Continue Working"): no long pauses.
- Applications: "Apply" from the posting, the profile is attached; the user submits when
  autonomy isn't granted.
