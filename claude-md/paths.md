# Named paths — defaults

The original source of each name. Without an override in `~/.kings-ai/paths.md` it's the standard;
with one, it fills only what the override doesn't cover (order in `global.md`, "Named paths").
Every value is an index (`README.md` / `index.md`) that maps the pages behind it.

| Name | Default | What it is |
|---|---|---|
| `DOCUMENTATION_STANDARD` | `~/.claude/docs/padrao-documentacao.md` | How docs are organized in a project: demands, decisions, studies |
| `SWIFT_STYLE_GUIDE` | `~/.claude/docs/KingsStyleGuide/Swift/README.md` | Swift code style and how screens are structured |
| `SWIFT_UNIT_TESTS` | `~/.claude/docs/KingsStyleGuide/Swift/UnitTests/README.md` | Swift unit test conventions: process, structure, mocks, triggers |
| `CAREER_PROFILE` | `~/.kings-ai/career/README.md` | The candidate's private career profile: facts, rules, form answers, templates and the applications pipeline (contract in the `kings-career` plugin) |
